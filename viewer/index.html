OpenTelemetry Trace Waterfall Viewer

Loads a merged span array (produced by merge_traces.py) and renders it as a Gantt-style waterfall. Fully offline — no server, no CDN, no charting library.

worker
error span
Expected input shape: a JSON array of span objects with trace_id, span_id, parent_span_id, name, service_name, kind, start_time_unix_nano, end_time_unix_nano, duration_ms, status, attributes — exactly what merge_traces.py writes. Generate one with: python merge_traces.py <trace_id> -o mytrace.json, then load that file above.
